Todo parece una eternidad.

Este proceso no es ajeno a la deidad.

¡La alquimia interior continúa golpeando el vacío!

Este proceso puede fallar.

Si la alquimia interior no es lo suficientemente fuerte, se abrirá paso y fallará.

Después de mucho tiempo.

representa un santo, el aire del emperador, ¡el supremo supremo!
