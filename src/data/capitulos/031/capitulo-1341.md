No hace falta decir que el nivel de mantenimiento del inventario se ha mejorado. Las cosas que antes no se podían guardar ahora se pueden guardar.

¡El modo del sistema de fusión puede fusionar cualquier elemento o arte marcial y combinar sus ventajas para eventualmente formar una habilidad o elemento único más fuerte!
