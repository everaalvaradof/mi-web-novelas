El sabor agridulce crea un aroma nostálgico.

Después de oler esta fragancia, el anciano no pudo evitar gritar: “Se parece mucho a esta fragancia. Esto es imposible”.

No lo creía. Es más, Estos dos elixires ordinarios pueden producirle una fragancia familiar. Después de quién sabe cuántos años, finalmente pudo oler esta fragancia.
